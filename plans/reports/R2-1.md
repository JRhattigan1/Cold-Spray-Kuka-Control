## Checked OK
- `test_part_axis_uses_cylinders` now runs and is not skipped, because the cylinders are on main. The full suite on main exited 0.
- CylFace: `part_axis` uses `.point`/`.axis`. The concentric residual (cross product of the directions plus the offset of the line) does not depend on axis sign or on which point on the axis is used, so bore vs outer does not matter to the solver.
- `centre_between` uses only the plane offset along b's normal, so the arbitrary `PlanarFace.point` is fine.
- Datum planes: the constraint `datum()` normals, origin (BASE origin) and offset sign (`n*offset`) match `sim/datums.py` exactly. The `"datum:XZ"` pick name parses correctly in `reference()`. `faceplate`/`table_axis` are BASE z=0 / BASE Z.
- `Part.without()`: planar, cylinders, coat_faces, base_face and start_face are all filtered by the face ids present. Face ids are not renumbered (only bodies are), which is consistent.
- step_io: cylinders and planar share the same per-body `index` counter and `n_faces` offset, and a face is never in both. The 6-tuple `tessellate_bodies` has only one caller (`pipeline.load_part`, updated). step_cache, mesh_cache and demo_part use `tessellate` (2-tuple), and test_slicing uses `tessellate_with_ids` (4-tuple), so neither changed.
- models: `infill_pattern` literals == `planner/patterns.PATTERNS` keys. `save_process` writes `'zigzag'`/`''` via repr, which is valid YAML (WP0r test). The commented `purge:` block in cell.yaml matches PurgeConfig field names and types.
