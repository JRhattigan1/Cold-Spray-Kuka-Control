## Decisions & deviations from the plan
- As instructed, the logic lives in a new module `planner/contour_tilt.py` and not inside `layers.py`, to avoid clashing with the patterns.py move.
- Outward side: the plan asked for the side to come from ring orientation alone. Ring orientation gives the normal's sign up to a flip, and the flip is decided per ring against `layer.region`'s boundary. This is robust to shapely ring orientation and to buffered/simplified rings.
- In `plan_layers`, the "last position" used for jump and turn decisions is now tracked as the aim xy (`here`, `last_ki`) instead of reading `path.moves[-1].pose[:2,3]`, because tilted nozzle xy ≠ aim xy. This is identical at tilt 0 (byte-identical KRL, regression test green).
- Tool Y keeps using the global X reference (`ALONG_X`), like the vertical path.
