## How to wire the process form (for the toolpath-form agent / E2)
```python
from coldspray.gui import widgets
# per advanced field row (put the label and the box in one row widget, then register the row):
chip = widgets.Chip()                                  # add it to the row, e.g. right of the box
widgets.advanced(row, changed=lambda: box.value() != default, chip=chip)
box.valueChanged.connect(widgets.refresh)             # re-check "changed" after edits
# (combos: currentIndexChanged; checkboxes: toggled)
```
- In Simple mode a field whose `changed()` is True stays visible and its chip reads "changed" (kind warn). In Advanced mode the chip is cleared. So Simple mode never hides a value that changes the output.
- To mark a field as advanced, use `field_level(name) == "advanced"` from models.py.
- `widgets.on_mode_changed(fn)` is the hook for anything that needs to re-lay out, e.g. hiding a Section that has become empty or setting a section chip such as "3 advanced hidden" from `hidden_count()`.
- Rule for later WPs: wrap controls most users won't need in `widgets.advanced(...)`.
- Caveat: a registered widget's visibility belongs to the registry, because `refresh()` calls `setVisible`. If other code also shows or hides a widget (e.g. `sm_part`), register a wrapper/container instead of the widget itself.
