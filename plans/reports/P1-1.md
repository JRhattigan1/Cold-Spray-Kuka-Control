## Done
- `cad/constraints.py` `angle`: at 0 deg the residual is now `a - b`, and at 180 deg it is `a + b` (both directions). It is smooth and fixes 2 DOF, so `dof_left` is right (4 for a single constraint, not 5). Other angles keep the dot residual.
- `distance(a, b, d, side=0)`: new `Constraint.side`. +1 puts `a` along b's normal, -1 puts it against the normal, and 0 (the default) still accepts either side. Any other value raises ValueError. For side 0 with d == 0, the signed offset is used, so the residual stays smooth at 0.
- `test_fast`: one warm-up solve, then the best of 5 timed solves, bound 0.1 s (was one run < 0.05 s). It still checks for ok and dof_left == 0.
- New tests: `test_angle_0_and_180_like_parallel[0, 180]`, `test_distance_side`, `test_distance_zero_is_smooth`.

## Notes
